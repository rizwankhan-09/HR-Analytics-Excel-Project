# HR Analytics Dashboard using Microsoft Excel

## Project Overview
This project analyzes employee workforce data using Microsoft Excel to identify patterns in employee distribution, salary, performance, job satisfaction, promotions, and attrition.

The goal is to transform raw employee data into meaningful insights that can support HR reporting and workforce-related decision-making.

## Project Objectives
- Clean and standardize employee data.
- Analyze employee headcount across departments and locations.
- Compare average salaries across departments.
- Examine employee attrition by department.
- Understand performance rating and salary band distributions.
- Explore employee demographics, job types, and overtime.
- Build an interactive dashboard using Excel PivotTables, PivotCharts, and slicers.

## Tools and Technologies
- Microsoft Excel
- Excel Tables and formulas
- Data cleaning and standardization
- PivotTables and PivotCharts
- Interactive slicers
- GitHub for project version control

## Dashboard Features
The dashboard includes KPI cards for:

- Total Employees
- Average Salary
- Attrition Rate
- Promoted Employees
- Average Job Satisfaction
- Overtime Employees

### Interactive Filters
Users can filter dashboard charts using slicers for:
- Department
- Location
- Gender
- Job Type
- Performance Rating
- Attrition

### Visualizations
The dashboard contains eight charts covering:
- Employee count by department
- Average salary by department
- Attrition by department
- Headcount by location
- Performance rating distribution
- Salary band distribution
- Job type distribution
- Gender distribution

## Project Structure
- `Data/` — Dataset used for analysis
- `HR_Analytics_Working.xlsx` — Excel workbook containing the data preparation, analysis, PivotTables, and dashboard

## How to Use
1. Open or download `HR_Analytics_Working.xlsx` from this repository.
2. Open the workbook in Microsoft Excel.
3. Navigate to the **Dashboard** sheet.
4. Use the slicers to filter the charts and explore different workforce segments.
5. Explore the analysis and PivotTables sheets for supporting details.
